Third Conditional konu anlatımı

If + had + V3 · Geçmişe dair hayalî koşullar

Third Conditional, geçmişte olmamış bir şeyin olsaydı nasıl sonuçlanacağını anlatır. Değiştirilemeyecek geçmiş için pişmanlık ve eleştiri bildirir: "Erken kalksaydım otobüsü kaçırmazdım."

Cümle yapısı

YapıIf + had + V3, + would have + V3If I had studied, I would have passed.Ders çalışsaydım geçerdim.
OlumsuzIf + hadn't + V3, + wouldn't have + V3If she hadn't helped, we wouldn't have finished.O yardım etmeseydi bitiremezdik.

Örnek cümleler

If I had left earlier, I wouldn't have missed the bus.

Daha erken çıksaydım otobüsü kaçırmazdım.

If you had told me, I would have helped you.

Bana söyleseydin sana yardım ederdim.

We would have won if our best player hadn't been injured.

En iyi oyuncumuz sakatlanmasaydı kazanırdık.

Sık yapılan hatalar

If I would have known, I would have come. → If I had known, I would have come.If bölümünde "would have" değil "had + V3".
If she had asked, I would help. → If she had asked, I would have helped.Geçmişe dair sonuç: would have + V3.

Kendini dene

Bu konudan 5 örnek soru. Cevabı görmek için soruya dokun; tüm alıştırmalar ve bölüm testi uygulamada.

1. If I ___ the alarm, I wouldn't have been late. (heard / had heard / would hear / have heard)

Cevap: had heard — If bölümü: had + V3.

2. She would have passed if she ___ harder. (studied / has studied / had studied / would study)

Cevap: had studied — Third conditional: had studied.

3. If we had taken a taxi, we ___ on time. (would arrive / would have arrived / will arrive / had arrived)

Cevap: would have arrived — Ana cümle: would have + V3.

4. If they ___ the map, they wouldn't have got lost. (had checked / checked / would check / check)

Cevap: had checked — had + V3.

5. I ___ you if I had known you were in town. (would call / will call / would have called / called)

Cevap: would have called — Geçmişe dair sonuç: would have called.
