Used to konu anlatımı

used to + V1 · Eskiden yapılan alışkanlıklar

"Used to", geçmişte düzenli olarak yaptığımız ama artık yapmadığımız şeyleri ya da eskiden doğru olup artık doğru olmayan durumları anlatır. Türkçedeki "-ardı / -erdi" (eskiden oynardım) yapısına benzer.

Ne zaman kullanılır?

  • Eski alışkanlıklar: I used to play football every day.Eskiden her gün futbol oynardım.
  • Eskiden geçerli olan durumlar: There used to be a cinema here.Eskiden burada bir sinema vardı.
  • Değişimi vurgulamak: She used to be shy, but now she's very confident.Eskiden utangaçtı ama şimdi kendine çok güveniyor.

Cümle yapısı

OlumluÖzne + used to + fiilin yalın hâliI used to live in Ankara.Eskiden Ankara'da yaşardım.
OlumsuzÖzne + didn't use to + V1He didn't use to like vegetables.Eskiden sebze sevmezdi.
SoruDid + özne + use to + V1?Did you use to have long hair?Eskiden saçların uzun muydu?

Örnek cümleler

I used to walk to school with my brother.

Eskiden kardeşimle okula yürüyerek giderdim.

There used to be a bakery on this corner.

Eskiden bu köşede bir fırın vardı.

She didn't use to drink coffee.

Eskiden kahve içmezdi.

Did you use to play an instrument?

Eskiden bir enstrüman çalar mıydın?

Sık yapılan hatalar

I use to live in Izmir. → I used to live in Izmir.Olumlu cümlede "used to" yazılır.
Did you used to smoke? → Did you use to smoke?did'li soru ve olumsuzda "use to" olur.
I used to living here. → I used to live here.used to'dan sonra fiilin yalın hâli gelir. (be used to + -ing farklı bir yapıdır.)

Kendini dene

Bu konudan 5 örnek soru. Cevabı görmek için soruya dokun; tüm alıştırmalar ve bölüm testi uygulamada.

1. When I was a child, I ___ afraid of the dark. (use to be / used to be / used to being / was used to be)

Cevap: used to be — Eski durum: used to be.

2. There ___ a park here, but now it's a car park. (used to be / use to be / used to have / is used to be)

Cevap: used to be — There used to be…

3. ___ you use to live near the sea? (Do / Were / Did / Have)

Cevap: Did — Soru: Did you use to…?

4. He didn't ___ like football. (used to / use to / uses to / using to)

Cevap: use to — Olumsuz: didn't use to.

5. We used to ___ to the village every summer. (go / going / went / gone)

Cevap: go — used to + V1: go.
