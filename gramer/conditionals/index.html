Conditionals 0, 1, 2 konu anlatımı

If cümleleri · Koşul cümleleri

Koşul cümleleri "eğer … ise" anlamı taşır ve iki bölümden oluşur: if bölümü (koşul) ve ana cümle (sonuç). Koşulun gerçek mi, olası mı yoksa hayalî mi olduğuna göre farklı zamanlar kullanılır.

Özet tablo

TürIf bölümüAna cümleAnlam
ZeroSimple PresentSimple PresentHer zaman doğru
FirstSimple Presentwill + fiilGerçek, olası gelecek
SecondSimple Pastwould + fiilHayalî, olası değil

Örnek cümleler

If you heat ice, it melts.

Buzu ısıtırsan erir.

If it rains tomorrow, we'll stay at home.

Yarın yağmur yağarsa evde kalacağız.

If I had more money, I would travel the world.

Daha çok param olsaydı dünyayı gezerdim.

If I were you, I'd accept the offer.

Senin yerinde olsam teklifi kabul ederdim.

Sık yapılan hatalar

If it will rain, I'll stay home. → If it rains, I'll stay home.If bölümünde "will" kullanılmaz.
If I would have time, I would help. → If I had time, I would help.Second conditional'da if bölümü Simple Past'tır.

Kendini dene

Bu konudan 5 örnek soru. Cevabı görmek için soruya dokun; tüm alıştırmalar ve bölüm testi uygulamada.

1. If you ___ water to 100 °C, it boils. (heat / will heat / heated / would heat)

Cevap: heat — Genel gerçek: Zero conditional.

2. If she studies hard, she ___ the exam. (passes / will pass / would pass / passed)

Cevap: will pass — Olası gelecek: First conditional.

3. If I ___ a bird, I would fly over the sea. (am / will be / were / would be)

Cevap: were — Hayalî durum: If I were…

4. We ___ late if we don't hurry. (are / would be / will be / were)

Cevap: will be — First conditional: will be.

5. What would you do if you ___ the lottery? (win / won / will win / would win)

Cevap: won — Second conditional: if + Simple Past.
