Be / Get Used To konu anlatımı

be used to + V-ing · Bir şeye alışkın olmak / alışmak

"Be used to" bir şeye alışkın olmayı, "get used to" ise bir şeye alışma sürecini anlatır. Burada "to" bir edattır; bu yüzden ardından isim ya da fiilin -ing hâli gelir. Bunu, eski alışkanlıkları anlatan "used to + V1" yapısıyla karıştırmamak gerekir.

Ne zaman kullanılır?

  • Alışkın olmak: I'm used to working at night.Gece çalışmaya alışkınım.
  • Alışmak (süreç): You'll soon get used to the weather here.Buranın havasına yakında alışırsın.
  • Alışkın olmamak: She isn't used to spicy food.Acılı yemeğe alışkın değil.

Cümle yapısı

Alışkın olmakÖzne + be + used to + V-ing/isimThey are used to the noise.Gürültüye alışkınlar.
AlışmakÖzne + get + used to + V-ing/isimShe got used to living alone.Yalnız yaşamaya alıştı.
OlumsuzÖzne + be + not + used to + V-ingI'm not used to waking up early.Erken kalkmaya alışkın değilim.

Özet tablo

YapıAnlamıÖrnek

Örnek cümleler

I'm used to cold weather; I grew up in Erzurum.

Soğuk havaya alışkınım, Erzurum'da büyüdüm.

It took me months to get used to the new job.

Yeni işe alışmam aylarımı aldı.

She isn't used to speaking in public.

Topluluk önünde konuşmaya alışkın değil.

You'll get used to it.

Alışırsın.

Sık yapılan hatalar

I'm used to wake up early. → I'm used to waking up early.be used to'dan sonra fiil -ing alır.
I used to working here. → I'm used to working here.Alışkın olmak anlamı için be gerekir (I'm used to).
I can't get use to it. → I can't get used to it.Yapı her zaman "used" ile kurulur.

Kendini dene

Bu konudan 5 örnek soru. Cevabı görmek için soruya dokun; tüm alıştırmalar ve bölüm testi uygulamada.

1. I'm used to ___ in a big city. (live / living / lived / to live)

Cevap: living — be used to + V-ing.

2. When I moved to London, it was hard to ___ the food. (get used to / used to / use to / be use to)

Cevap: get used to — Alışma süreci: get used to.

3. She ___ a lot when she was young, but now she doesn't. (is used to travel / used to travel / is used to travelling / gets used to travel)

Cevap: used to travel — Eski alışkanlık: used to + V1.

4. Don't worry, you'll get used to ___ glasses. (wear / wearing / wore / worn)

Cevap: wearing — get used to + V-ing.

5. He isn't used to ___ such hot weather. (having / have / had / to have)

Cevap: having — be used to + V-ing: having.
