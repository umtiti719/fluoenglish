Mixed Conditionals konu anlatımı

karışık koşul cümleleri · Geçmiş ve şimdiyi birleştiren koşullar

Karışık koşul cümleleri, koşulun bir zamanda, sonucun başka bir zamanda olduğu durumları anlatır. En sık kullanılanı: geçmişte olan (ya da olmayan) bir şeyin şimdiki sonucunu hayal etmek. "Dün gece uyusaydım şimdi yorgun olmazdım" gibi.

Ne zaman kullanılır?

  • Geçmiş koşul → şimdiki sonuç: If I had taken the job, I would be rich now.O işi kabul etseydim şimdi zengin olurdum.
  • Şimdiki/kalıcı durum → geçmiş sonuç: If I spoke French, I would have understood the film.Fransızca bilseydim filmi anlardım.
  • Pişmanlık ve hayal: If she hadn't moved, we would still be neighbours.O taşınmasaydı hâlâ komşu olurduk.

Cümle yapısı

Geçmiş → şimdiIf + had + V3 + would + V1If I had studied medicine, I would be a doctor now.Tıp okusaydım şimdi doktor olurdum.
Şimdi → geçmişIf + V2 + would have + V3If I were braver, I would have said something.Daha cesur olsaydım bir şey söylerdim.

Örnek cümleler

If I had saved more money, I would be on holiday now.

Daha çok para biriktirseydim şimdi tatilde olurdum.

If she hadn't missed the train, she would be here by now.

Treni kaçırmasaydı şimdiye burada olurdu.

If I were more organised, I wouldn't have forgotten your birthday.

Daha düzenli biri olsaydım doğum gününü unutmazdım.

If they had invested in 2010, they would be millionaires today.

2010'da yatırım yapsalardı bugün milyoner olurlardı.

If he didn't speak Japanese, he wouldn't have got the job.

Japonca bilmeseydi işi alamazdı.

We would be lost now if you hadn't brought the map.

Haritayı getirmeseydin şimdi kaybolmuş olurduk.

Sık yapılan hatalar

If I had taken the job, I would have lived in Paris now. → If I had taken the job, I would live in Paris now."Now" sonucun şimdiye ait olduğunu gösterir; bu yüzden would + V1 kullanılır.
If I would have known, I would be there. → If I had known, I would be there now."If"li kısımda "would" kullanılmaz; geçmiş koşul had + V3 ile kurulur.
If I was taller, I would have joined the team. → If I were taller, I would have joined the team.Resmî dilde varsayım kısmında "were" tercih edilir; günlük dilde "was" da duyulur.

Kendini dene

Bu konudan 5 örnek soru. Cevabı görmek için soruya dokun; tüm alıştırmalar ve bölüm testi uygulamada.

1. If I ___ breakfast, I wouldn't be hungry now. (had eaten / ate / have eaten / would eat)

Cevap: had eaten — Geçmiş koşul (had eaten) → şimdiki sonuç (wouldn't be).

2. If she were more careful, she ___ the vase. (wouldn't break / wouldn't have broken / didn't break / hadn't broken)

Cevap: wouldn't have broken — Kalıcı özellik (were careful) → geçmiş sonuç (wouldn't have broken).

3. If we had left earlier, we ___ there now. (would have been / will be / would be / are)

Cevap: would be — Sonuç şimdi: would be.

4. I ___ you if I didn't trust you. (wouldn't have helped / won't help / hadn't helped / don't help)

Cevap: wouldn't have helped — Genel durum (didn't trust) → geçmiş sonuç (wouldn't have helped).

5. If he ___ the lottery, he wouldn't be working here. (won / had won / has won / would win)

Cevap: had won — Geçmiş koşul: had won.
